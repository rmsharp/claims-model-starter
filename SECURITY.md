# Security Policy

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security-sensitive reports.**

Instead, report privately using one of these channels:

- GitHub's private vulnerability reporting: open a [security advisory](https://github.com/rmsharp/claims-model-starter/security/advisories/new) on this repository, **or**
- Contact the maintainer directly: `rmsharp` on GitHub.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof of concept if available.
- The affected version/commit.

## Response

This is a single-maintainer, pre-production project. There is no formal SLA, but reports are
triaged as they arrive and a fix or mitigation is prioritized over other open work. You will
receive an acknowledgment; expect it may take a few days given this is not a staffed security
team.

## Scope

This policy covers the code in this repository (`model_project_constructor` and
`model_project_constructor_data_agent`). It does not cover the third-party dependencies listed in
`THIRD-PARTY-LICENSES` — report vulnerabilities in those packages to their own maintainers.

## Disclosure

Please give a reasonable period to address a reported issue before any public disclosure. There is
currently no bug-bounty program.
